# Подключение к FastAPI

Изменены только `src/api/chatApi.js` и `vite.config.js`. Внешний вид и компоненты страницы сохранены. Во время разработки запрос `/api/chat` идёт через Vite на `http://127.0.0.1:8000/chat`.

1. Запустите PostgreSQL и бэкенд в отдельном терминале из папки `backend`:
   ```cmd
   .venv\Scripts\activate
   fastapi dev main.py --host 127.0.0.1 --port 8000
   ```
2. Проверьте `http://127.0.0.1:8000/health` — должен ответить `{"status":"ok"}`.
3. В папке `frontend` выполните `npm ci` и `npm run dev`. Если Vite уже работает, перезапустите его после изменения `vite.config.js`.
4. Откройте сайт и спросите: «Сколько заявлений подано на Экономику в 2026 году?»

Пока бэкенд поддерживает только вопросы о заявлениях на Экономику с годом. Настройка прокси относится к режиму `npm run dev`; при публикации потребуется маршрутизация `/api` на бэкенд.
